▣ RemoteDesk

Auf einen Computer zugreifen

Code und PIN stehen in der RemoteDesk-App auf dem Computer, den du steuern möchtest.

RemoteDesk-App herunterladen

Installiere die App auf dem Computer, den du fernsteuern willst. Beim ersten Start legst du eine PIN fest – danach ist der Computer mit seinem festen Code immer erreichbar.
